# 婚礼 MV 完成情况核查

核查日期：2026-10-01。核查分支：`codex/ai-wedding-mv`。

## 结论

**原始产品 Spec 的 P0 尚未全部完成，也尚不能交付真实 AI 婚礼 MV。** 当前实现提供了可演示的业务工作流、私有素材访问、预算控制、模型协议和 FFmpeg 渲染代码。真实模型适配器仍缺失，故事和静帧制作主要依赖用户手动操作，演示 provider 只输出标记为 DEMO ONLY 的静态卡片。

[原始 Spec](superpowers/specs/2026-10-01-ai-wedding-mv-design.md) 与[实施计划](superpowers/plans/2026-10-01-ai-wedding-mv-implementation.md)的范围有差异：实施计划以 demo 模式作为完成判据。因此，演示计划的完成不能推导为产品 P0 全部完成，也不能推导为可上线。

## 本轮修复

视频资产读取原先先检查渲染状态并返回成功，之后才检查项目所有者/参与者作用域。这使其他已登录账号可以在知道 asset ID 时读取别人的预览或已批准成片，其他项目参与者也可以读取预览。

- RED：新增 4 种跨项目读取用例，原代码 3 失败、1 通过；失败响应为实际视频字节的 HTTP 200。
- GREEN：先校验账号/参与者所属项目，再校验授权和渲染状态；新增 4 项与原有撤回授权、正常读取测试共 6 项通过。
- 回归测试提交：`293f779`；修复提交：`0748afb`。
- 本次测试使用合成的私有字节验证授权边界，不作为有效 MP4 编码质量的证据。
